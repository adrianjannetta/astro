The physics, scales and assumptions

Keplerian two-body model. Orbital motion is calculated from Kepler’s equation, using the combined stellar and planetary mass. Eccentric orbits speed up near periapsis. The same stellar line-of-sight velocity drives the arrow, spectrum and graph.

Doppler shift: Δλ / λ₀ ≈ vᵣ / c, with c = 299,792,458 m/s. Positive velocity is away from the observer. A constant system velocity is set to zero. Light-travel delay, relativity, stellar rotation, activity and measurement noise are omitted.

Period and amplitude: P² = 4π²a³ / G(M★ + Mₚ); K = (2πa★ / P) sin i / √(1 − e²), where a★ = a Mₚ / (M★ + Mₚ). The displayed minimum mass Mₚ sin i is the usual approximation when Mₚ ≪ M★.

Orbit scale: the main orbital paths use a common distance scale. The inset independently enlarges the star’s orbit; its magnification is labelled. Marker sizes do not represent stellar or planetary radii. Camera rotation changes only the illustration; inclination changes the physical orbit relative to the observer.

Spectrum: synthetic absorption lines illustrate the method, rather than a calibrated stellar atmosphere. The selected line has a rest wavelength of 589.000 nm. Teaching mode multiplies only the line shifts, with separate labelled factors for the broad spectrum and line detail. Numerical wavelength readings always give the true physical shift. In true-scale mode an Earth analogue’s displacement is almost invisible.

Presets: idealised systems, not fitted observations. All start edge-on. One animation cycle represents one orbit, regardless of its actual duration. Radial velocity at the NASA Exoplanet Archive ↗
